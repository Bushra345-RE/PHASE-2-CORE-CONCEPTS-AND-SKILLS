# Phase 2 — Core Concepts and Skills

## Project: Student Performance Analyzer

This project demonstrates practical Python core concepts through a small,
readable application.

### Concepts demonstrated
- Variables and data types
- Lists and dictionaries
- Loops and conditional statements
- Functions and return values
- Classes and objects
- Constructor and instance attributes
- Modules and packages
- Basic documentation
- Formatted output

## Run the project

```bash
python main.py
```

### Expected result

The program displays each student's marks, average, and grade.

## Purpose

The project is designed as a stepping stone between learning individual
Python concepts and applying them together in a small practical application.
